# HR Analytics Dashboard

## Project Overview
This project analyzes employee data using MySQL and Microsoft Power BI to understand workforce distribution, employee demographics, and hiring trends.

## Tools Used
- MySQL
- SQL
- Microsoft Power BI

## Project Objectives
- Calculate total employees and average employee age.
- Analyze remote and headquarters workforce percentages.
- Visualize hiring trends by year.
- Analyze employees by gender, race, department, and state.
- Present key HR insights through an interactive dashboard.

## Key Findings
- Total employee records: 22,214
- Average employee age: 38.43 years
- Headquarters workforce: 75.25%
- Remote workforce: 24.75%
- Largest department: Engineering, with 6,686 employees

## Visualizations
- KPI cards
- Hiring trend line chart
- Gender distribution donut chart
- Employees by state bar chart
- Employees by department bar chart
- Employees by race bar chart

## Conclusion
MySQL was used to query and analyze employee data, while Power BI was used to create visualizations and present workforce insights.

## Future Scope
- Analyze employee attrition and retention.
- Improve workforce planning.
- Study recruitment trends to support future hiring decisions.
